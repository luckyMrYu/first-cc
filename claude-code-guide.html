🎯 什么是 Claude Code？

Claude Code 是一个强大的 AI 编程助手，可以直接在你的终端中运行。它能够帮助你：

  • 理解和探索代码库
  • 编写和修改代码
  • 调试和修复问题
  • 执行命令和操作文件
  • 进行代码审查
  • 管理 Git 操作

Claude Code 就像一个经验丰富的程序员同事，随时准备帮助你解决各种编程问题。它可以读取你的项目文件、理解代码结构、执行命令，并且能够记住你的偏好和项目的上下文。

✨ 核心功能

📖 代码理解

可以读取和分析整个代码库，理解项目结构、依赖关系和代码逻辑。帮你快速上手新项目。

✏️ 代码编辑

可以直接创建、修改和删除文件。支持精确的代码替换，保持代码格式和风格。

🔍 智能搜索

快速搜索文件、函数、变量等。支持正则表达式和复杂的搜索模式。

💻 命令执行

可以在你的环境中执行各种命令，如运行测试、安装依赖、启动服务等。

🌐 网络访问

可以搜索网络信息、获取文档、访问 API，帮助你解决技术难题。

🧠 记忆系统

可以记住你的偏好、项目信息和重要决策，跨会话保持一致性。

🤖 多智能体

可以启动专门的子智能体来并行处理复杂任务，提高效率。

📊 工作流

支持创建复杂的多步骤工作流，自动化重复性任务。

🔰 基本使用方法

1. 自然语言对话

最简单的方式就是直接用自然语言和 Claude Code 对话：

  • "帮我解释一下这个项目的结构"
  • "找到所有处理用户登录的代码"
  • "给这个函数添加错误处理"
  • "运行测试看看有什么问题"

2. 斜杠命令

以 / 开头的命令可以快速执行特定操作。例如：

  • /help - 查看帮助信息
  • /clear - 清除对话历史
  • /memory - 查看和编辑记忆

3. 权限确认

💡 提示：Claude Code 在执行可能影响系统的操作（如运行命令、修改文件）时，会先向你请求许可。这是为了保护你的系统安全。你可以在权限弹窗中选择允许或拒绝。

4. 上下文感知

Claude Code 会自动感知：

  • 当前工作目录
  • Git 仓库状态
  • 项目结构和文件
  • 你提到的文件和代码

📋 斜杠命令大全

🔧 基础命令

/help
功能：显示帮助信息和使用指南
用法：直接输入 /help
说明：查看 Claude Code 的基本使用方法和可用命令
/clear
功能：清除对话历史
用法：直接输入 /clear
说明：开始新的对话，清除之前的上下文。注意：这不会删除文件修改或 Git 操作
/memory
功能：查看和编辑记忆
用法：直接输入 /memory
说明：打开记忆编辑器，可以查看、添加、修改或删除 Claude 记住的信息。记忆会跨会话保持
/config
功能：配置设置
用法：/config 或 /config <设置项> <值>
说明：查看和修改 Claude Code 的配置，如主题、模型、权限等
/model
功能：切换 AI 模型
用法：/model 或 /model <模型名称>
说明：选择不同的 Claude 模型。可用模型包括：sonnet（快速）、opus（强大）、haiku（最快速）、fable（平衡）
/resume
功能：恢复之前的会话
用法：直接输入 /resume
说明：继续之前保存的对话会话，可以从列表中选择要恢复的会话
/login
功能：登录账户
用法：直接输入 /login
说明：登录你的 Claude 账户以使用完整功能
/logout
功能：登出账户
用法：直接输入 /logout
说明：登出当前账户
/cost
功能：查看 token 使用情况
用法：直接输入 /cost
说明：显示当前会话的 token 使用量和费用信息
/doctor
功能：诊断问题
用法：直接输入 /doctor
说明：检查 Claude Code 的安装和配置问题，并提供修复建议
/status
功能：查看当前状态
用法：直接输入 /status
说明：显示当前会话的状态信息，包括模型、工作目录、权限模式等
/compact
功能：压缩对话历史
用法：直接输入 /compact
说明：压缩当前对话以节省 token，保留关键上下文
/bug
功能：报告 bug
用法：直接输入 /bug
说明：打开 GitHub issue 页面报告 Claude Code 的 bug
/release-notes
功能：查看发布说明
用法：直接输入 /release-notes
说明：查看当前版本的发布说明和新特性
/vim
功能：切换 vim 模式
用法：直接输入 /vim
说明：启用或禁用 vim 风格的键盘快捷键
/pr-comments
功能：查看 PR 评论
用法：直接输入 /pr-comments
说明：查看当前 PR 的评论和反馈

🎨 代码审查与分析

/init
功能：初始化项目文档
用法：直接输入 /init
说明：为当前项目生成 CLAUDE.md 文档，记录项目信息和指导原则
/code-review
功能：代码审查
用法：/code-review 或 /code-review <PR编号> 或 /code-review --fix
说明：审查代码变更，查找潜在问题和改进点。可以指定 PR 编号、分支或路径。使用 --fix 自动应用修复建议
/security-review
功能：安全审查
用法：/security-review
说明：对当前分支的变更进行安全审查，查找潜在的安全问题和漏洞
/simplify
功能：简化代码
用法：/simplify
说明：审查变更的代码，查找可以简化的部分并应用修复，提高代码质量
/review
功能：通用审查
用法：/review
说明：对代码进行综合审查，包括质量、风格和最佳实践

🚀 开发与运行

/run
功能：运行项目
用法：/run
说明：启动并运行当前项目的应用，查看实际效果。支持多种项目类型（CLI、服务器、浏览器应用等）
/loop
功能：循环执行任务
用法：/loop <间隔> <命令> 例如 /loop 5m /code-review
说明：在指定间隔重复执行命令，用于持续监控或定期检查
/dataviz
功能：数据可视化
用法：/dataviz
说明：创建图表、图形、仪表板等数据可视化内容

⚙️ 配置与优化

/update-config

/keybindings-help

📚 API 与开发

/claude-api

用法：/claude-api
说明：查阅 Claude API / Anthropic SDK 的参考文档，包括模型 ID、定价、参数、流式传输等
/workflow-authoring

用法：/workflow-authoring

💡 使用技巧

1. 提供清晰的上下文

当你提到特定的文件或功能时，尽量提供具体信息：

  • ✅ 好的例子："修改 src/auth/login.ts 中的验证逻辑"
  • ❌ 模糊的例子："修改登录代码"

2. 分步骤处理复杂任务

对于复杂的任务，可以分步骤进行：

  1. 先让 Claude 分析问题
  2. 讨论解决方案
  3. 确认方案后再执行修改

3. 使用记忆功能

对于重要的项目信息或你的偏好，可以让 Claude 记住：

  • "记住：这个项目使用 TypeScript"
  • "记住：我喜欢使用函数式编程风格"

4. 利用 Git 集成

Claude Code 可以帮你管理 Git 操作：

  • "查看当前的 Git 状态"
  • "提交这些更改"
  • "创建一个 Pull Request"

5. 多任务并行

对于独立的任务，可以要求 Claude 并行处理：

  • "同时检查这三个文件的问题"
  • "并行运行这些测试"
⚠️ 注意：Claude Code 可以执行系统命令。在执行可能破坏性的操作（如删除文件、修改系统配置）时，一定要仔细检查权限确认弹窗。

6. 快捷键

提高使用效率的快捷键：

  • Esc - 中断当前操作
  • Ctrl+C - 取消当前命令
  • ↑/↓ - 浏览历史命令
